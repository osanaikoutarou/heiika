# 【2】読みやすく＋平易に（heiika-2-plain）

ほかのスキルの手順書は読まず、**書き換えは1回、採点は最後に1回**で行う（採点を見て直す往復はしない。下げ幅は1〜2割分小さくなるが、時間は1/3）。

```bash
PY=$HEIIKA/.venv/bin/python
TOOL=$HEIIKA/tools
```

## 読み手
指定がなければ `heiika-check` の「読み手の既定」: AI が知っているユーザーの属性に合わせる。ただし少し簡単寄り（知っている分野でも、日常的に使う語だけ残し、迷ったら言い換える）。分からない分野は中高生〜大学生くらいとみなす。

## 手順
1. 文章を一時ファイルに書く。
2. つながりの読みにくさを機械で測る: `$PY $TOOL/c_metrics.py 文章のファイル --detail`。出力の「C の直し: 必要／不要」（総量が `C_TRIGGER`＝20点以上なら必要）を見る。
   - **不要なら、C のことは考えずに書き換える。**
   - 必要なら、内訳の「文をまたいで前を指す言葉」で点の高いもの（目安: 距離30字超）と、「まとまりごとの新出」で知らない語が多いまとまりを控え、下の書き換えの中で一緒に直す（指示語は指す先の名詞に戻す。新出の多いまとまりは話題ごとに分け、見出しがなければ短い名前の見出しを付ける）。
3. 次の操作で書き換える。**下書きは1回。書き直さない。**
   - 文を切る（1文1つの内容。目安40字以内）。順番を変える（結論・依頼を先に）。
   - 「このため」「それ」のような指示語は指す先の名詞に戻す（文を切ったり段落を分けたりしたら、その直後の文の頭の指示語も名詞に戻す。切った分だけ指す先が遠くなるため）。省かれた主語・対象は補う。
   - 用語は、読み手が知らないものだけ短い一般語に言い換える。元の語の括弧での併記は重要な語だけ（言い換えた語の2割以下）。
   - 並列は箇条書きにしてよい。前提が後ろにあれば先に出す。
   - しないこと: 内容の省略・要約・例え・情報の追加。引用・表・コードは変えない。
4. 採点を1回だけ: 元と結果に `$PY $TOOL/scorer.py --brief` と `$PY $TOOL/c_metrics.py`。報告のためだけに使う（結果を見て直さない）。

## 出力
書き換えた文章と、次の報告（1〜3行）。
```
- 難しさ: 文の点数 〇 → 〇、つながりの点数 〇 → 〇（高いほど難しい）
- 言い換えた語: 「元」→「後」（主なもの）。意味が変わった可能性のある箇所があれば1行
- 読み手の想定: …
```
