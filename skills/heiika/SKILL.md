# heiika（平易化）: 読みやすくする入口

AI の文章が長くて難しいときに、読みやすく書き換える。方法は5つ。

## 前提
- このリポジトリの場所を環境変数 `HEIIKA` に入れておく（例: `export HEIIKA=~/heiika`）。採点ツールは `$HEIIKA/.venv/bin/python $HEIIKA/tools/scorer.py`。
- 対象: 指定がなければ、直前の AI の発言。文章やファイルを指定されたらそれ。対象は一時ファイルに書き出してから使う。
- 読み手: 指定がなければ `heiika-check` の「読み手の既定」（AI が知っているユーザーの属性に合わせ、少し簡単寄り。分からない分野は中高生〜大学生くらい）。

## 方法を決める
番号や言葉で方法を言われていれば、そのまま実行する。言われていなければ、次の一覧をそのまま出して、**番号で**答えてもらう（番号と中身をセットで示す）。

```
どの方法にしますか？ 番号で答えてください（ふだんは 2 がおすすめ）
1. 読みやすく: 意味は変えない。文を切る・並べ替える
2. 読みやすく＋平易に: 1 に加えて、用語も言い換える
3. 構造を組み直す: 構造化して、見出しと段落に分ける。意味は変えない（重い）
4. 構造を組み直す＋平易に: 3 の結果を平易にする（重い）
5. 仕様書風にする: 条件・例外・定義にラベルを付けた箇条書き（重い）
```

## 各方法の中身
| 番号 | スキル | 中身 | 重さの目安（1,000字） |
|---|---|---|---|
| 1 | `heiika-1-simplify` | 意味を変えずに読みやすく。文を切る・順番を変える・指示語を名詞に戻す。採点を見ながら最大3回直す | 2〜3分 |
| 2 | `heiika-2-plain` | 1 の操作＋用語の言い換え。書き換え1回の軽い手順。つながりの読みにくさ（指示語・新出語）も必要なときだけ直す | 1〜2分 |
| 3 | `heiika-3-restructure` | 構造化（`heiika-structure`）→ まとまりごとに見出し、主張ごとに段落 → つながりの点数を見て指示語と段落を直す | 3〜4分 |
| 4 | `heiika-4-restructure-plain` | 3 の結果に `heiika-compress` を、省略なしでかける | 4〜5分 |
| 5 | `heiika-5-spec` | 3 の構造から、条件・例外・定義・範囲にラベルを付けた1項目＝1仕様の箇条書きにする | 3〜4分 |

- 3・4・5 は構造化が入るので重い。条件・例外・定義が込み入った文章（仕様書、契約、法令、長い設計の説明）のときに選ぶ。
- どれも AI の発言1つごとに自動でかける（hook）には重い。頼まれたときに使う。
- 採点ツール（`tools/`）は、書き換えの判断に内部で使う。**点数はユーザーに見せない**（聞かれたときだけ答える）。

## 出力
- 結果をチャットに返す。長い場合（目安2,000字超）はファイルにも書き出し、パスを伝える。
- 最後に1〜2行で、言い換えた語（2・4 のとき）と、読み手の想定を添える。点数は書かない。
