# 【4】構造を組み直す＋平易に（heiika-4-restructure-plain）

```bash
PY=$HEIIKA/.venv/bin/python
TOOL=$HEIIKA/tools
```

## 手順
1. `heiika-3-restructure` を行う（まだなら）。結果を `〈名前〉_3.md` とする。
2. その結果に `heiika-compress` を、次の制限でかける → `〈名前〉_4.md`
   - 構成（見出しの数・順番・階層）は残す。見出しも本文も平易に短くする。文体は「です・ます」にそろえる。
   - 使ってよい操作: 文を切る・順番を変える・指示語を名詞に戻す・用語の言い換え・前提の先出し。
   - 用語の言い換え: 読み手が知らないものだけ。元の語の括弧での併記は、重要な語と読めない固有名詞だけ（言い換えた語の2割以下）。
   - しないこと: 内容の省略・要約・例え・情報の追加。引用・表・コードは変えない。
   - 読み手: 指定がなければ `heiika-check` の「読み手の既定」。
3. 1文ごとの段落になっていたら、同じ話題の2〜4文を1段落にまとめ、段落の頭に足した「なので」「それなのに」を減らして自然にする。
4. 採点: 元・3・4 それぞれに `$PY $TOOL/scorer.py --brief` と `$PY $TOOL/c_metrics.py`。
5. 元の文章の主張を1つずつ挙げ、残っているかを確かめる。言い換えで意味が変わった可能性のある箇所を一覧にする。

## 出力
平易にした文章と、次の報告。
```
- 文の点数: 元 〇 → 3 〇 → 4 〇。つながりの点数: 同じく
- 言い換えた語: 「元」→「後」（主なもの）
- 意味が変わった可能性のある箇所: 「元」→「後」 — どう変わりうるか
- 読み手の想定: …
```
